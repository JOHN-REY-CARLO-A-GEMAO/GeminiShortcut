# Contributing to Quick Gemini Pro

Thank you for your interest in contributing! Since this is a simple extension, the process is straightforward.

## 🛠 Setup for Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/GeminiShortcut.git
   ```
2. **Open Chrome:**
   - Go to `chrome://extensions`.
   - Enable **Developer Mode** (toggle in the top right).
   - Click **Load unpacked**.
   - Select the folder where you cloned this repo.

3. **Make Changes:**
   - Edit files (`content.js`, `background.js`, `popup.html`, etc.).
   - Go back to `chrome://extensions` and click the **Refresh** icon on the extension card.
   - Reload your test webpage to see the changes.

## 🐛 Found a Bug?
Please open an issue in this repository describing the problem and how to reproduce it.

## ✨ Want to Add a Feature?
1. Fork the repository.
2. Create a new branch (`git checkout -b feature/AmazingFeature`).
3. Commit your changes.
4. Push to your branch and open a Pull Request!
